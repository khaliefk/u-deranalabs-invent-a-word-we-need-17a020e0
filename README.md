# Invent a Word We Need

A brand-new English word for the chain of goodbyes at the end of a phone
call. `main.py` (standard library only) writes the entry to
`/output/entry.txt`.

Entry (76 characters):

> Goodbyeloop (n.): the five goodbyes after the first goodbye on a phone call.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
